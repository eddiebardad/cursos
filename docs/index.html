Datos que se entienden.

Manual ilustrado del CLI stateless que extrae metadatos de cursos gratuitos, los normaliza con Pydantic v2 y los entrega en JSON-LD o CSV para la curaduría en Omeka S. El extractor enlaza a los proveedores: no aloja sus cursos.

Schema.org Dublin Core Omeka S v4+ n8n

Parte A del Hito 1 · cuatro proveedores operativos · datos públicos sujetos a revisión editorial.

1. Arquitectura del ecosistema

La separación de responsabilidades evita que el extractor se convierta en una base de datos o en un cliente directo de Omeka S. n8n orquesta y el repositorio semántico conserva el catálogo curado.

Identidad y cambios. n8n compara la URL canónica del curso y la huella SHA-256 de sus campos descriptivos para decidir si lo registra o actualiza.

2. Los cuatro proveedores v1

▦

ms_learn

Microsoft Learn · API de catálogo.

Extrae learning paths por defecto; los módulos requieren --enable-modules.

Idioma: inglés y español. Los cursos se modelan como acceso gratuito según la metadata del proveedor.

◎

openlearn

The Open University · sitemap comprimido, extruct y DOM.

Idioma predominante: inglés. Solo atribuye certificado/insignia gratuita con señal explícita de la ficha.

◈

aprende

Aprende.org · API JSON en español.

Consulta los detalles necesarios de forma perezosa y no inventa descripciones ausentes.

⌘

netacad

Cisco Networking Academy · catálogo SPA con Playwright.

Solo emite tarjetas con gratuidad explícita. Si la tarjeta no declara credencial gratuita, no la presume.

Filtro anti-falsos gratis: no se acepta acceso obligatorio de pago ni una prueba temporal como curso gratuito.

3. Contrato Unix y códigos de salida

La salida estructurada y la observabilidad son canales independientes. Esta separación permite encadenar el CLI con n8n, PowerShell, Bash o validadores JSON sin contaminar el payload.

uv run cursodex run -p openlearn --limit 5 --output - \
  > cursos.jsonld 2> ejecucion.log
CódigoSignificadoInterpretación operativa
0Éxito, uno o más cursosValida `needs_review` y continúa con curaduría.
1Excepción, red, parsing o argumentosConsulta `stderr` y `run_summary`.
2Sin cursos y sin error técnicoRevisa URL, filtros o cambios de API/DOM.

4. Un modelo, dos vistas semánticas

El modelo estático Course normaliza el registro una vez. Los exportadores proyectan los metadatos en Schema.org y Dublin Core; los datos de deduplicación y curaduría se conservan en campos privados para el flujo de n8n.

Sin categoría válida: Pendiente_Categoria queda en _cursodex_meta.category y se omiten las propiedades públicas schema:about y dcterms:subject.

5. Recetario CLI

Los paneles se pueden desplegar para copiar la receta. Los comandos de muestra usan los nombres canónicos de proveedor y el ejecutable instalado por uv.

Instalación reproducible · PowerShell 
git clone https://github.com/eddiebardad/cursos.git
Set-Location cursos
uv sync --frozen --link-mode=copy
uv run playwright install chromium
Instalación reproducible · Bash 
git clone https://github.com/eddiebardad/cursos.git
cd cursos
uv sync --frozen --link-mode=copy
uv run playwright install chromium
Prueba rápida de cada proveedor 
uv run cursodex run -p ms_learn --limit 5 --output -
uv run cursodex run -p openlearn --limit 5 --output -
uv run cursodex run -p aprende --limit 5 --output -
uv run cursodex run -p netacad --limit 5 --output -
CSV para importación o JSON-LD a archivo 
uv run cursodex run -p aprende --limit 100 --output cursos.csv --format csv
uv run cursodex run -p openlearn --limit 20 --output cursos.jsonld

El CSV es UTF-8 sin BOM; usa `;` para valores multivalor. JSON-LD es adecuado para el flujo de ingesta de n8n.

Microsoft Learn: añadir módulos 
uv run cursodex run -p ms_learn --enable-modules --limit 10 --output -

Por defecto Microsoft Learn extrae learning paths; activa módulos solo si necesitas ese nivel de granularidad.

URL individual y BFS genérico controlado 
uv run cursodex run --url "https://www.open.edu/openlearn/<area>/<curso>" --output -
uv run cursodex run --url "https://example.org/catalog" --enable-bfs --max-pages 20 --limit 10

Usa la URL real de la ficha. BFS está desactivado por defecto y solo se activa explícitamente para sitios sin adaptador.

OpciónPropósito
--url, -uURL de catálogo o curso; el dominio detecta el proveedor.
--provider, -pms_learn, openlearn, aprende o netacad.
--output, -oArchivo de destino o - para stdout (JSON-LD por defecto).
--format, -fcsv o jsonld; si se omite, se infiere y - usa JSON-LD por defecto.
--limit, -lMáximo de cursos válidos; 0 no limita.
--renderPlaywright para JavaScript; NetAcad siempre lo usa.
--enable-bfsActiva el rastreo BFS genérico.
--enable-modulesAñade módulos de Microsoft Learn a learning paths.
--max-pagesMáximo de páginas de BFS; por defecto 100.

6. Payloads de ejemplo

Ejemplo abreviado con la forma real que utiliza el exportador Omeka S. Cada valor de propiedad incluye el identificador de propiedad automático. Las propiedades privadas quedan marcadas expresamente.

[
  {
    "@type": ["o:Item", "schema:Course"],
    "o:is_public": false,
    "schema:name": [
      {"type": "literal", "property_id": "auto", "@value": "Introducción a Python", "@language": "es"}
    ],
    "schema:url": [
      {"type": "uri", "property_id": "auto", "@id": "https://example.edu/courses/python"}
    ],
    "schema:description": [
      {"type": "literal", "property_id": "auto", "@value": "Fundamentos del lenguaje y sus herramientas.", "@language": "es"}
    ],
    "schema:about": [
      {"type": "literal", "property_id": "auto", "@value": "Programación y Desarrollo de Software"}
    ],
    "schema:identifier": [
      {"type": "literal", "property_id": "auto", "@value": "urn:cursodex:sha256:<sha256>", "is_public": false}
    ],
    "schema:dateModified": [
      {"type": "literal", "property_id": "auto", "@value": "2026-01-15T12:00:00Z", "is_public": false}
    ],
    "dcterms:title": [
      {"type": "literal", "property_id": "auto", "@value": "Introducción a Python"}
    ],
    "dcterms:subject": [
      {"type": "literal", "property_id": "auto", "@value": "Programación y Desarrollo de Software"}
    ],
    "_cursodex_meta": {
      "canonical_url": "https://example.edu/courses/python",
      "content_hash": "<sha256>",
      "category": "Programación y Desarrollo de Software",
      "access_type": "free_no_certificate",
      "needs_review": false,
      "review_notes": []
    }
  }
]

El hash y la fecha son marcadores ilustrativos. En una extracción, el modelo los calcula o asigna. Si la categoría es pendiente, elimina del payload público las claves schema:about y dcterms:subject; el bloque privado conserva la categoría para curaduría.

CSV: cabeceras canónicas

dcterms:title,dcterms:identifier,dcterms:publisher,dcterms:creator,dcterms:description,dcterms:language,dcterms:subject,schema:name,schema:url,schema:description,schema:provider,schema:author,schema:about,schema:keywords,schema:timeRequired,schema:educationalLevel,schema:inLanguage,schema:isAccessibleForFree,schema:educationalCredentialAwarded,schema:coursePrerequisites,schema:image,canonical_url,content_hash,access_type,needs_review,review_notes,last_seen_at

En el archivo CSV real, la coma es el delimitador de columnas; los valores de listas dentro de una celda se separan por punto y coma.

8. Normalización y triaje automático

Identidad

HTTPS, host normalizado, tracking eliminado y query params funcionales preservados.

Descripción

HTML y entidades limpiados; texto acotado legalmente a un máximo de 350 caracteres.

Duración

Convertida a ISO 8601, por ejemplo 4 días → P4D.

Huella

SHA-256 estable de los campos descriptivos y pedagógicos; no incorpora el timestamp.

¿Cuándo se activa needs_review?

  • La descripción está ausente o tiene menos de 30 caracteres.
  • No se pudo normalizar el idioma.
  • La categoría resulta Pendiente_Categoria.
  • Una duración proporcionada no pudo interpretarse como ISO 8601.

review_notes registra motivos legibles para que una persona pueda priorizar la curaduría. Un nivel educativo ausente no basta por sí solo para activar la revisión.

Principio de catálogo limpio: los registros sin categoría siguen siendo útiles para triage, pero no contaminan las facetas públicas del grafo RDF.

9. Resolución de problemas

ProblemaAcción
Falta Chromium / error PlaywrightEjecuta uv run playwright install chromium en el entorno activo.
Código 2 y []Consulta proveedor, URL y `run_summary`; puede haber un cambio externo en DOM o API.
HTTP 403 / WAFRespeta las restricciones del proveedor, revisa conectividad y vuelve a intentar más tarde; no evadas controles.
Salida estructurada mezclada con mensajesSepara los canales con > datos 2> logs; no redirijas ambos a un mismo flujo JSON.
Acentos incorrectos en hoja de cálculoImporta explícitamente el CSV con codificación UTF-8.
Descripción corta o categoría pendienteLee review_notes y resuelve la metadata en la curaduría.
